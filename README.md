# GuideShot 🎥 (v0.1)

Create engaging video tutorials effortlessly by combining screenshots with voice narration. GuideShot is an open-source screen capture tool that transforms your screenshots and voice recordings into seamless video content.

## Features

- 📸 Screenshot capture with voice recording
- 🎤 Voice narration synchronization
- 🎬 Automatic video generation
- 💻 Simple and intuitive interface

## Coming Soon

- 🔄 Supabase backend integration
- 👥 Multi-tenant support with team collaboration
- ✏️ Advanced editor
- 🤖 AI-powered features
- ☁️ Self-hosting capabilities

## About

GuideShot is and always will be free and open-source, designed to empower content creators, educators, and professionals to create high-quality tutorial videos without the complexity of traditional video editing tools.
